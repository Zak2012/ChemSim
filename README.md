# ChemSim
This project is meant to help students and teachers. It is used to visualise what happened during a chemical reaction to give a deeper understanding.

## >>>[Download](https://github.com/Zak2012/ChemSim/releases)

### Libraries used
- FreeType
- GLEW
- GLFW
- GLM
- OpenGL
- Rectpack2D
- STB
- Emscripten
